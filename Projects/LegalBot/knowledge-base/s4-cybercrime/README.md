# Segment 4: Cyber Crime Response

## Overview
Online fraud, UPI scams, digital arrest, hacking, sextortion, phishing, fake loan apps

**Key Laws:** IT Act 2000, BNS 2023, NCRP  
**Difficulty:** Medium  
**CRITICAL:** Golden Hours Protocol (first 24-72 hours decide recovery)

## Knowledge Pack (60-100 entries required)

### Topics to Cover

#### A. Immediate Response - Golden Hours (15 entries) ⚠️ PRIORITY
- **Within 30 minutes:**
  - Call 1930 Cybercrime Helpline
  - Call bank fraud number (SBI: 1800-1234, ICICI: 1860-1200-7777, etc.)
  - File NCRP complaint: cybercrime.gov.in
- **Evidence preservation:**
  - Screenshot everything immediately
  - Do NOT delete messages
  - Save transaction IDs, UPI references
  - Collect phone numbers, account numbers
- **Freezing funds:**
  - Bank can freeze within hours if reported quickly
  - After 72 hours, recovery <10%

#### B. Types of Cybercrimes (20 entries)
