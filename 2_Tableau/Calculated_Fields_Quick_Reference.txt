====================
CALCULATED FIELDS
====================

--- CUSTOMER SEGMENTATION ---

Active Customers:
IF [Active Category] = "Active Customer" THEN [CustomerID] END

Inactive Customers:
IF [Active Category] = "Inactive Customer" THEN [CustomerID] END

Exit Customers:
IF [Exit Category] = "Exit Customer" THEN [CustomerID] END

Retained Customers:
IF [Exit Category] = "Retain Customer" THEN [CustomerID] END

Credit Card Holders:
IF [Category] = "credit card holder" THEN [CustomerID] END

Non Credit Card Holders:
IF [Category] = "non credit card holder" THEN [CustomerID] END


--- COUNT METRICS (FOR KPI CARDS) ---

Total Customers:
COUNTD([CustomerID])

Active Customers Count:
COUNTD([Active Customers])

Inactive Customers Count:
COUNTD([Inactive Customers])

Exit Customers Count:
COUNTD([Exit Customers])

Retained Customers Count:
COUNTD([Retained Customers])

Credit Card Holders Count:
COUNTD([Credit Card Holders])

Non Credit Card Holders Count:
COUNTD([Non Credit Card Holders])


--- TIME CALCULATIONS ---

IMPORTANT: If Bank Departure shows as "Abc" (text) instead of calendar icon,
use DATE() function to convert:

Year:
YEAR(DATE([Bank Departure]))

Month Name:
DATENAME('month', DATE([Bank Departure]))

Month Number:
MONTH(DATE([Bank Departure]))

If Bank Departure is recognized as Date type, simpler version:
YEAR([Bank Departure])
DATENAME('month', [Bank Departure])
MONTH([Bank Departure])

NOTE: Using [Bank Departure] field for exit/churn analysis (2016-2019)


--- CREDIT TYPE GROUPING ---

Credit Type (groups credit scores):
IF [Credit Score] >= 800 THEN "Excellent"
ELSEIF [Credit Score] >= 740 THEN "Very Good"
ELSEIF [Credit Score] >= 670 THEN "Good"
ELSEIF [Credit Score] >= 580 THEN "Fair"
ELSE "Poor"
END

Use this for the "Exit by Credit Type" horizontal bar chart.


--- TREND ANALYSIS ---

For line charts showing trends over time:
- Use Year + Month Name in Columns
- Exit Customers Count in Rows
- Sort Month Name by Month Number

CHART-SPECIFIC TIPS

====================================================================
TROUBLESHOOTING COMMON ISSUES
====================================================================

❌ DATE FIELD SHOWING AS TEXT (Abc not 📅):
   Solution 1: Data Source tab → Click Abc icon → Select "Date"
   Solution 2: Use DATE() wrapper in formulas:
               YEAR(DATE([Bank Departure]))
               DATENAME('month', DATE([Bank Departure]))
   Solution 3: Fix Excel file:
               - Widen column to see if ##### shows dates
               - Format Cells → Date → m/d/yyyy
               - Look for green triangles → Convert to Number
               - Save & Refresh Tableau

❌ YEAR([Bank DOJ]) GIVES ERROR:
   Problem: Field is text, not date
   Solution: Use YEAR(DATE([Bank DOJ])) instead

❌ CALCULATED FIELDS SHOWING 0:
   - Verify exact field spelling: [CustomerID] vs [Customer ID]
   - Right-click field → Show Filter to see actual values
   - Check exact string match: "Active Customer" not "Active"
   - Try CONTAINS(): IF CONTAINS([Active Category], "Active")

❌ COUNTD SHOWS 0 FOR CUSTOMER SEGMENTS:
   - Check the base calculated field (Active Customers, Exit Customers)
   - Verify the IF condition matches your data exactly
   - Test: Create text field [Active Category] to see actual values
