LEFT PANEL: SLICERS (Vertical stack)
───────────────────────────────────────────────────────────────────────────────

Width: ~15-20% of dashboard width
All slicers: Dropdown style

Slicer 1: SELECT YEAR
  • Field: DateTable[Year]
  • Default: (All)
  • Options: 2016, 2017, 2018, 2019, 2020, 2021, 2022

Slicer 2: SELECT MONTH
  • Field: DateTable[Month]
  • Default: (All)
  • Options: January - December

Slicer 3: GEOGRAPHY LOCATION
  • Field: Geography[GeographyLocation]
  • Default: (All)
  • Options: France, Spain, Germany

Slicer 4: ACTIVE CATEGORY
  • Field: ActiveCustomer[ActiveCategory]
  • Default: (All)
  • Options: Active Member, Inactive Member

Slicer 5: EXIT CATEGORY
  • Field: ExitCustomer[ExitCategory]
  • Default: (All)
  • Options: Exit, Retain

Slicer 6: GENDER CATEGORY
  • Field: Gender[GenderCategory]
  • Default: (All)
  • Options: Male, Female

Slicer 7: CATEGORY (Credit Card)
  • Field: CreditCard[Category]
  • Default: (All)
  • Options: credit card holder, non credit card holder

RESET FILTERS BUTTON
  • Position: Below slicers
  • Background: Teal (#5B9BD5)
  • Text: White, "Reset Filters"
  • Action: Clear all filters

SIZING AND SPACING GUIDELINES
═══════════════════════════════════════════════════════════════════════════════

KPI Cards (Top Row):
  • Height: ~10-12% of canvas
  • Width: Each card ~14% of canvas width (7 cards = ~98% width)
  • Spacing: 1-2% gap between cards
  • Alignment: Top aligned, evenly spaced

Left Slicer Panel:
  • Width: 15-20% of canvas
  • Height: Remaining canvas height
  • Each slicer: ~12-15% height
  • Button: Below last slicer

Main Content Area (Charts):
  • Width: 75-80% of canvas (remaining space)
  • Top Chart (Column): ~35% height
  • Middle Chart (Line): ~30% height
  • Bottom Charts (3 charts): ~30% height, split into thirds

General:
  • Margins: 2-3% around all edges
  • Gutter: 2% between major sections
  • Consistent alignment and spacing

TEXT AND FORMATTING STANDARDS
═══════════════════════════════════════════════════════════════════════════════

Card Titles:
  • Font: Segoe UI
  • Size: 10-12pt
  • Style: Regular
  • Color: Dark Gray
  • Position: Top or bottom (below number)

Card Values:
  • Font: Segoe UI or Segoe UI Bold
  • Size: 32-40pt
  • Style: Bold
  • Color: Black
  • Format: #,##0 (with thousands separator)

Chart Titles:
  • Font: Segoe UI
  • Size: 12-14pt
  • Style: Bold or Italic
  • Color: Black
  • Alignment: Left or Center

Axis Labels:
  • Font: Segoe UI
  • Size: 10pt
  • Style: Regular
  • Color: Dark Gray

Data Labels:
  • Font: Segoe UI
  • Size: 9-10pt
  • Style: Regular
  • Color: Black or White (depending on background)
  • Format: #,##0 for counts, 0.0% for percentages

Slicer Headers:
  • Font: Segoe UI
  • Size: 11pt
  • Style: Bold
  • Color: Black

TIPS FOR MATCHING REFERENCE IMAGE
═══════════════════════════════════════════════════════════════════════════════

1. Alignment is Key:
   • Use Align tools (Format → Align → Distribute horizontally/vertically)
   • Snap to grid (View → Snap to grid ON)
   • Use guides for precise alignment

2. Consistent Spacing:
   • Select all cards → Align → Distribute horizontally
   • Keep equal gaps between all elements
   • Use Format Painter to copy formatting

3. Color Consistency:
   • Set color palette once, apply everywhere
   • Use custom colors for exact match
   • Test color combinations for accessibility

4. Typography:
   • Stick to Segoe UI throughout (Power BI default)
   • Use max 2-3 font sizes for hierarchy
   • Bold for emphasis, not size changes

5. Visual Hierarchy:
   • KPIs at top (most important)
   • Slicers on left (controls)
   • Detailed charts in main area (analysis)

6. White Space:
   • Don't cram visuals too close
   • Leave breathing room around elements
   • Clean, uncluttered design
