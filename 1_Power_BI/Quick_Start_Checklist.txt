PHASE 1: DATA IMPORT (10 minutes)
═══════════════════════════════════════════════════════════════════════════════

□ Step 1.1 - Open Power BI Desktop
□ Step 1.2 - Click "Get Data" → Excel
□ Step 1.3 - Browse to Bank Project.xlsx
□ Step 1.4 - Check ALL these tables:
    □ Bank Departure
    □ CreditCard
    □ ActiveCustomer
    □ CustomerInfo
    □ ExitCustomer
    □ Gender
    □ Geography
□ Step 1.5 - Click "Load"
□ Step 1.6 - Wait for data to load

═══════════════════════════════════════════════════════════════════════════════
PHASE 2: DATA MODEL SETUP (15 minutes)
═══════════════════════════════════════════════════════════════════════════════

□ Step 2.1 - Go to MODEL VIEW (left sidebar icon)

□ Step 2.2 - Create DateTable:
    □ Go to Modeling tab → New Table
    □ Copy DAX from "Bank_Dashboard_DAX_Measures.txt" (DateTable formula)
    □ Press Enter
    □ Right-click DateTable → Mark as Date Table → Select [Date]

□ Step 2.3 - Create 7 Relationships (drag from table to table):
    □ Bank Departure[GeographyID] → Geography[GeographyID]
    □ Bank Departure[GenderID] → Gender[GenderID]
    □ Bank Departure[HasCrCard] → CreditCard[HasCrCard]
    □ Bank Departure[IsActiveMember] → ActiveCustomer[IsActiveMember]
    □ Bank Departure[Exited] → ExitCustomer[ExitID]
    □ Bank Departure[CustomerId] → CustomerInfo[CustomerId]
    □ Bank Departure[Bank DOJ] → DateTable[Date]

□ Step 2.4 - Verify all relationships are:
    □ Many to One (*)
    □ Single direction (arrow pointing to "1" side)
    □ Active (solid line, not dotted)

═══════════════════════════════════════════════════════════════════════════════
PHASE 3: CREATE CALCULATED COLUMN (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

□ Step 3.1 - Go to DATA VIEW (left sidebar icon)
□ Step 3.2 - Click on "Bank Departure" table
□ Step 3.3 - Go to Table tools → New Column
□ Step 3.4 - Copy "CreditCategory" formula from DAX file
□ Step 3.5 - Press Enter
□ Step 3.6 - Verify column shows: Excellent, Very Good, Good, Fair, Poor

TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Problem: Numbers don't match validation
→ Check relationships in Model View
→ Verify using DISTINCTCOUNT, not COUNTROWS

Problem: Slicers don't filter charts
→ Use Edit Interactions (Format tab)
→ Verify relationships exist

Problem: Previous Month shows blank
→ Mark DateTable as date table
→ Check Date relationship to Bank DOJ

Problem: Charts show errors
→ Check field names match exactly
→ Verify calculated column was created
